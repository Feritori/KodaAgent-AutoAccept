# KodaAgent-AutoAccept

Программа сама захватывает окно VSCode и читает его каждые 2 секунды, при изменении окна агента или появлении кнопки Да/ОК/Allow сама нажимает на неё.

Автоматическое нажимание кнопки Да/OK/Allow
